# data_encoding

What it does: Compresses bytes, decompresses them, and checks integrity.

Algorithm design:
- Compress input bytes with `zlib`.
- Decompress and verify round-trip equality.
- Hash original content with `sha256`.

Why this design:
- Keeps correctness checks very clear.
- Compression ratio + hash gives easy quality signals.

Input: Generated byte payload.

Output: `input_bytes`, `compressed_bytes`, `ratio`, `roundtrip`, `sha256`.
